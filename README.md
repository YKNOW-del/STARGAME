# 星轨厨房 STARGAME

轻量级天文合成题材益智网页游戏 —— 软件工程课程项目（选题一·游戏类）。

参考《合成大西瓜》的合成链与《胡闹厨房》的订单装配，将玩法重构为**轨道槽位系统**：
向环绕恒星的轨道槽位投放天体，同轨相邻同级自动合并并向外轨迁移；按"星座订单"合成并交付
指定天体（交付即计数离场），点亮全部星座即通关。合成链共 15 级，按太阳系天体**真实质量升序**
排列（星尘→彗星→小行星→冥王星→月球→水星→火星→金星→地球→天王星→海王星→土星→木星→太阳→黑洞）。

## 运行方式

- **桌面版 / 移动版**：现代浏览器（Chrome/Edge）直接打开对应 HTML 即可，无需安装、无需后端。
  注意桌面版依赖同目录下的 `mobile/core/starchef-core.js`（整体文件夹一起拷贝）。
- **核心测试**：`node mobile/core/core.test.js`（15 项：合成外迁/黑洞吞噬/冰冻派生/崩溃判定/
  三星边界/阈值推导公式与关卡表一致性等）。
- **RN 原生骨架**：见 `mobile-native/README.md`（init RN 工程 → 拷贝 src → 安装 Skia 依赖 → run-android）。

## 核心特性

- 10 关三章（类地行星 / 外太阳系 / 恒星演化），关卡阈值按推导公式配置（`maxDrops=⌈1.5×D_min⌉`）
- 订单星座（交付点亮）、质量计分（真实千克数，M⊕/M☉ 显示）、三星评级、本地排行榜与署名
- 变体天体：冰卫星（冻结相邻槽位）、脉冲星（引爆清除同轨）；超新星、黑洞吞噬、终章黑洞交付
- 陨石 3 秒预警、彗星漂移、潮汐滑移 / 弃置道具、引力崩溃判定
- 17 条图鉴（真实数据 + 科普）、战绩海报导出、色弱/减动效模式、新手教程
- 纯前端零后端：三端（桌面/移动/RN）共享同一份核心逻辑模块，规则单点维护
